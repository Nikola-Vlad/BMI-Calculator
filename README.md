# BMI Calculator

A simple BMI Calculator built with HTML, CSS and JavaScript.

## Features

- Calculate BMI using Metric units (kg/cm)
- Calculate BMI using US units (lbs/ft/in)
- Switch between Metric and US units
- Display BMI results and BMI category
- Reset the calculator
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript

## What I Learned

- Working with DOM manipulation
- Handling user input
- Using event listeners
- Performing calculations with JavaScript
- Creating responsive layouts with CSS

## How to Use

1. Select Metric or US units.
2. Enter your height and weight.
3. Click **Calculate BMI**.
4. Your BMI and BMI category will be displayed.
